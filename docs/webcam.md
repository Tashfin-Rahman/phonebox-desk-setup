# Phone as a webcam

## Built into Windows 11
1. On the Android phone, install **Link to Windows** (Android 9+).
2. On the PC: Settings → Bluetooth & devices → Mobile devices → allow access → **Manage devices** → add the phone →
   turn on **Use as a connected camera**.
3. In OBS, Discord or Zoom, pick the phone as the camera. The rear camera is sharper.

## If the PC has no Bluetooth (desktop on Ethernet)
Use **DroidCam** or **Iriun**: free apps that work over USB or home Wi-Fi.

Note: a phone used as the webcam can't show the PhoneBox panel at the same time.
